# Snake Game

A simple Snake game implemented in Python using Tkinter.

## Features

- Move the snake using arrow keys or WASD keys
- Eat food to grow longer
- Collision detection with walls and self
- Score tracking
- Victory condition when the snake fills the board

## Controls

- **Left**: Arrow Left or 'A'  
- **Right**: Arrow Right or 'D'  
- **Up**: Arrow Up or 'W'  
- **Down**: Arrow Down or 'S'  

## Requirements

- Python 3.x  
- Tkinter

## How to Run

1. Clone the repository  
2. Navigate to the project folder  
3. Run the game:

```bash
python main.py
